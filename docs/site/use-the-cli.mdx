---
title: Use Shiitake from the terminal
description: The fungi CLI runs a Shiitake Agent on your machine.
---

You do not have to write a host to talk to a Shiitake Agent. The `fungi`
command-line app is a Shiitake Agent with a terminal interface. Run it in a
project folder; it keeps each conversation as a durable Session you can resume
later.

The Fungi documentation covers it, so this page only points the way:

- [Install the Fungi CLI](https://docs.fungi.computer/install/): one npm
  install, then `fungi` in your project folder.
- [Use the terminal](https://docs.fungi.computer/guides/use-the-terminal/): give
  work, find it again, resume and stop.
- [Use Fungi in your editor](https://docs.fungi.computer/guides/use-fungi-in-your-editor/):
  connect Zed, Neovim or another ACP client to the same Agent.
- [CLI reference](https://docs.fungi.computer/reference/cli/): every command and
  option.

The CLI can use your own provider key or subscription, or Fungi's hosted models.
When you want your own behaviour inside an Agent, continue with
[Your first extension](../extensions/first-extension/).
