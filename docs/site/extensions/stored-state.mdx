State is a set of typed, keyed collections the extension owns. Shiitake stores
them durably next to the Session, so they survive a restart. This page turns
`bookmarks.check` into `bookmarks.add`, which saves the link, and lists the
saved links in the prompt.

## Declare a collection

<Code code={extension} lang="ts" title="extension.ts" />

`.state({ bookmarks: defineCollection(...) })` declares one collection. Its
schema is the only decoder for stored rows. `key` names a row; saving the same
key again replaces it. `index` groups rows so the prompt can read one Session's
links without scanning everyone's.

## Write and read

The tool writes through `ctx.state.update`, one short synchronous transaction.
The prompt reads through `ctx.state.read`. Both are plain functions: no promises
inside, and no network calls while the transaction is open.
