A projection is the extension's public view of one Session. Clients read it;
they never open the extension's tables. This page projects the saved links.

## Add a projection

<Code code={extension} lang="ts" title="extension.ts" />

Two lines are new since the last page. `projection` declares the schema clients
decode and a `read` function that returns the value for one Session. It runs
while Shiitake builds a Session snapshot, so it reads with the synchronous
`peekPage`. An empty list is a real value: no bookmarks is useful to a client.

In the tool, `s.observe(run.sessionId)` tells Shiitake the Session changed.
Subscribed clients receive the new projection once the write commits.
