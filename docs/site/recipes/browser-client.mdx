Supply your host's base URL and retain one request ID for retries of this

model reply. Read or subscribe through the returned Session client for progress.

## Where it lives in Fungi

Grove uses this client through its admitted App host to open a Session and
observe its messages in the inbox. The browser keeps the returned Session
client; the host retains responsibility for admission and reconciliation.

## Guarantee and limits

The maintained client parses HTTP responses and preserves typed refusals.
Authentication, Team membership and Session authority belong to the server; this
helper supplies none of them. The excerpt compiles against public exports.
Running it requires an existing admitted HTTP host; it is not a standalone
credential-free host demonstration. For that, use
[Quickstart](../../quickstart/).
